# ARCHEION — User Guide

## 1. Quick Start
1. **Launch ARCHEION Desktop:**
   - On first launch, create a new local repository on an internal drive or external SSD.
   - Choose whether to enable AES-256-GCM encryption. If encrypting, record your recovery key safely.
2. **Connect your Android Device:**
   - Connect via USB with USB Debugging enabled (or install the ARCHEION Companion APK).
   - If prompted on your phone, authorize the USB Debugging connection.
3. **Audit Capabilities:**
   - View truthful capabilities probed directly from the device and current permissions.
4. **Create a Backup Plan:**
   - Select categories (Photos, Videos, Audio, Documents, Contacts, Calendar, App Inventory, APKs).
   - Click **Start Backup**. Watch real-time streaming progress, verified chunk hashes, and manifest creation.
5. **Explore & Verify:**
   - Use **Backup Explorer** to browse files offline without reconnecting the phone.
   - Export any file with verified SHA-256 integrity.
6. **Compare & Restore:**
   - Compare snapshots over time to inspect added, changed, or deleted items.
   - Perform safe, conflict-aware restores with pre-flight previews.
