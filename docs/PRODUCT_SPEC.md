# ARCHEION — Product Specification & Requirements

This document captures the formal requirements defined in `ARCHEION_Updated_Engineering_Master_Prompt.md`:
- Offline-first local backup library.
- Zero telemetry, zero accounts, zero cloud dependencies.
- Non-root baseline using public Android APIs and ADB interfaces.
- AES-256-GCM authenticated encryption with 256-bit recovery keys.
- Streaming object store with content addressing and atomic snapshot commits.
- Backup Explorer with search, preview, and safe export.
- Snapshot comparison with added/modified/removed classification.
- Conflict-aware, non-destructive restore engine.
